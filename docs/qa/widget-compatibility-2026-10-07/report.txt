--------------

private effective inherited ticker widget and returning enabled, default true.
Nested TickerMode computes ancestorEnabled && localEnabled. It has no valuesOf.
The current 3.41.7 source implements of(context) with the same inherited
subscription and boolean. valuesOf(context).enabled reads the same effective
boolean and subscribes to the same inherited widget. forceFrames is irrelevant
to these visibility guards. Both paths notify on effective inherited changes.
Using getNotifier().value would lose the inherited subscription and is also
deprecated on current; manual ancestor walking would duplicate framework logic.
